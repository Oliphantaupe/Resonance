# Spark UI Screenshots

Screenshots captured from the Spark Application UI at `http://localhost:4040` during the AA4 performance experiments.

## How to capture

1. Start the pipeline: `.\run_local.ps1 -Stage pipeline` (or `make pipeline` in Docker)
2. Open `http://localhost:4040` in a browser **while the pipeline is running**
3. Navigate to the **SQL / DataFrame** tab to see query plans and stage timings
4. Navigate to **Stages** for shuffle read/write bytes

## Expected screenshots (add after running)

| Filename | What to capture |
|----------|----------------|
| `exp1_aqe_off_stages.png` | Stages tab with AQE disabled — note high stage count and shuffle bytes for `silver.charts_enriched` |
| `exp1_aqe_on_stages.png` | Same stage with AQE enabled — fewer post-shuffle tasks, coalesced partitions |
| `exp2_broadcast_query_plan.png` | SQL tab query plan showing `BroadcastHashJoin` for the countries join |
| `exp3_repartition_dag.png` | DAG visualization showing pre-repartition stage before the sort-merge join |
