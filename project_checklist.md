## Audit Notes (2026-05-09)

### ✅ Passing (confirmed by code review)
- All outputs write Delta format: Bronze `partitionBy("year")`, Silver charts `partitionBy("region","year")`, Silver enriched `partitionBy("region","year")` (coarsened from region/year/month to avoid driver result-size overflow), Gold (unpartitioned — known gap, see below)
- Explicit schemas for all 3 sources (`src/bigdata_music/schemas.py`)
- Advanced window functions: `row_number()`, `dense_rank()`, `SUM OVER`, 90-day rolling `rangeBetween`, gap-and-island with `date_sub`
- Broadcast join for the 63-row countries table (`silver/join_enriched.py`)
- AQE enabled (`spark_session.py`), pre-repartition on join key (`join_enriched.py`)
- Silver cleaning: corrupt-record capture, multi-format date coalesce, nullability filters, deduplication via `row_number()`
- Dashboard reads only Gold Delta tables via `deltalake` Python lib — no SQLite, no raw data
- 5 dashboard pages each linked to a Gold table and Spark pattern (documented in `de_report.md §5`)
- Critical reflection in `de_report.md §6` with 5 concrete improvement points
- MLflow: `set_experiment`, `start_run`, `log_params`, `log_metric`, `log_input` (datasets), `log_artifact`
- `conf/catalog.yml`: Kedro-style Data Catalog for all 13 datasets
- `data/README.md`: data provenance with MD5 hashes and source URLs
- `CLAUDE.md`: AI navigability file with commands, architecture, Windows gotchas
- `reports/perf_report.md`: real wall times (AQE ON run: silver.charts_enriched=220.6s, total ~666s)
- MLflow fixed: removed empty `mlflow/` shadow directory, installed mlflow==2.13.0

### ⚠️ Known limitations (documented in `de_report.md §6`)
- Gold tables are unpartitioned — dashboard filters by `year` at read time; pre-partitioning would improve cold-load time
- Bronze uses `mode("overwrite")` — CDC/Delta MERGE would be better for incremental runs
- No salting on `track_id` — viral tracks create skewed partitions in the charts × tracks join
- `spark.driver.maxResultSize` raised to 4g — needed because `partitionBy("region","year")` produces ~200 output files whose task metadata exceeds the 1g default
- Spark UI screenshots not captured (require manual browser capture at `http://localhost:4040` during a live pipeline run)
