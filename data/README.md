# Data Provenance

This directory is **not tracked by Git** (see `.gitignore`). The files below must be downloaded before running the pipeline.

## Raw sources (`data/raw/`)

| File | Size | MD5 | Source |
|------|------|-----|--------|
| `charts.csv` | 3,322 MB | `a9fc40a65504bc6c551521d08cf050ba` | [Spotify Charts 2017–2021 — Dhruvil Dave, Kaggle](https://www.kaggle.com/datasets/dhruvildave/spotify-charts) |
| `track_features.parquet` | 4,097 MB | `d547baf143b4a7fc16285e7668fdbea3` | [Spotify Tracks Dataset — GildasLeDrogoff, HuggingFace](https://huggingface.co/datasets/GildasLeDrogoff/spotify-tracks-dataset) |
| `countries.csv` | < 1 MB | `2f88117ab7495eb783869450b0af97d7` | Hand-crafted (World Bank / Wikipedia), committed in repo |

## Re-download

```powershell
python scripts/download_data.py --source kaggle   # charts.csv (requires KAGGLE_TOKEN env var)
python scripts/download_data.py --source hf       # track_features.parquet
python scripts/download_data.py --source verify   # verify hashes of existing files
```

## Derived data (`data/bronze/`, `data/silver/`, `data/gold/`)

Generated by `python -m bigdata_music.pipeline`. Fully reproducible from `data/raw/` — delete and re-run if anything looks wrong.

All derived layers are Delta Lake format. Read with `deltalake.DeltaTable(path)` (dashboard) or `src/bigdata_music/utils/delta_io.read_delta(spark, path)` (pipeline — Windows-safe workaround, see `CLAUDE.md`).

## Why data is not in DVC

The raw files total ~7.4 GB. DVC would require a remote storage backend (S3, GCS, etc.) which is outside the scope of this academic project. The MD5 hashes above serve as the provenance record: if your `data/raw/` files match these hashes, your pipeline results will be identical.
